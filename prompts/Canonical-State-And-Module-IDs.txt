IDS CANONICOS DE ESTADOS E MODULOS

REGRA DE OURO

Nenhum prompt, gate, agente, indice de IDs, snapshot ou log pode criar ou alterar estado.
Apenas a State Machine pode alterar estado.

---

REGRA DE COMMIT

Ao concluir qualquer alteracao solicitada neste arquivo ou derivada dele, criar commit local com mensagem clara e escopo fechado.
O commit deve incluir somente arquivos relacionados a alteracao executada.
Se nao houver alteracao de arquivo, registrar explicitamente que nao ha commit a criar.
Nao incluir mudancas externas, geradas ou nao relacionadas sem solicitacao explicita.

---

REGRA DE USO

Sempre que registrar snapshot, log, auditoria ou relatorio, usar o ID canonico quando aplicavel.

Nem todo modulo canonico precisa ter prompt dedicado.
Quando nao houver prompt de modulo especifico, o modulo deve ser tratado pela fase ativa correspondente e pela Module-Phase-Matrix.txt.
Um modulo canonico nao cria estado e nao autoriza ultrapassar a camada permitida pela State Machine.
